# What each ArduCopter mode does with the pilot's throttle (plan drone-configurator-joystick-backend.md, section 11.1, from
# ArduCopter's source). number | name | class, where the class is: climb (the throttle is a climb rate: its middle is no climb),
# ignores (the mode commands the altitude and takes no throttle from the pilot) or thrust (the throttle is thrust: its middle is
# about hover, no altitude hold). A mode that is not here is thrust. The page (`lib/rc/modes.ts`) and the backend (`rcmodes.pi`) are
# both held to this file.
